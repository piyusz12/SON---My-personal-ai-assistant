# Controlled Terminal Skill

Enforces zero-trust PowerShell execution.

## Critical Protections
- **No Arbitrary Scripts**: Never executes raw shell strings generated by the LLM.
- **Safe Startup Flags**: Always includes `-NoProfile -NonInteractive -ExecutionPolicy RemoteSigned`.
- **Injection Defense**: Checks for argument delimiters, shell piping, and forbidden cmdlets.
- **Binary Resolution**: Validates executables against `ExecutableRegistry` within trusted system paths.
